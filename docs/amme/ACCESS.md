## Что внутри админки

1. **Дашборд** — гости, кухня, выручка, журнал
2. **Записи** — пришёл / неявка / импорт / ручное добавление
3. **Счета** — меню, чек, баня, walk-in (раньше называлось «Гости»)
4. **CRM** — профили гостей, сегменты, заметки, история, VIP
5. **Кухня** — тикеты с таймером срочности
6. **Отчёты** — сегодня / 7д / 30д / свой период, графики, печать
7. **Меню** — цены и вкл/выкл позиций
8. **Справка** — статьи как пользоваться (включая CRM)

### Мини-шпаргалка смены

1. Открыть **Записи** → сверить список / импорт.
2. **Пришёл** → уходит в **Счета**.
3. Бить блюда в чек → уходят на **Кухню**.
4. **Оплатить** → **Закрыть счёт**.
5. Постоянного гостя смотреть в **CRM** (телефон важен).
