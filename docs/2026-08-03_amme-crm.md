# AMMÉ CRM (Aug 3, 2026)

Hospitality-style guest CRM layered on guest-accounting ops.

## What shipped

- `AmmeGuest` profile: phone-keyed identity, notes, tags, dietary, birthday, VIP/blocked, banya preference
- Auto-link on booking create / import / arrive / walk-in
- Stats: visitCount, noshowCount, lifetimeSpend, avgSpend, first/last visit
- Segments: all, VIP, regular (3+), new, dormant 30d+, banya, high spend, noshow, blocked
- UI: sidebar **CRM**, badges on bookings/visits, receipt alert with notes + CRM deep-link
- API: `GET/POST /api/amme/crm`
- Backfill: `npm run db:backfill-amme-crm`
- E2E: `npm run test:amme-e2e`

## Sources for feature set

Hotel CRM patterns (unified profile, segments, front-desk notes) adapted to banya+kitchen — not full messaging automation.
